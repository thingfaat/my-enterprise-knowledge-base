# 企业智能知识库：从源码学习到完整实现

## 使用说明

本计划根据本地项目的模块与源码入口初步编排，不是知识星球原课程目录的复刻。学习者会 Java，Spring Boot 尚不熟悉，每天可投入 4 小时；SQL 熟练度待学习中确认。以 Java 后端为主，前端用于理解完整交互。当前只完成目录、依赖声明及部分文档检查，尚未逐条核实业务实现，也未进行运行验证；表中的主题和验收是待验证的学习目标，不代表功能已完整实现。

每天 4 小时：回顾 15 分钟 → 原理讲解 45 分钟 → 源码追踪 60 分钟 → 独立练习 90 分钟 → 验收与记录 30 分钟。一天只追一条主要调用链。卡住时记录预期、实际结果、日志与猜测，环境排障可单独增加一天。每周第 7 天用于复盘和补欠，不强求日历连续。

最终目标：学习者能够理解整体架构和关键设计，亲手写出自己的完整企业智能知识库，覆盖后端业务、前端交互、中间件集成与可复现的启动验收，并能独立处理变化需求。

## 学习阶段与完成边界

下面 49 个学习单元是第一阶段，不是整个项目的完成期限。一个单元可按实现难度拆成多个实际学习日；后续继续执行 [完整项目实现里程碑](完整项目实现里程碑.md)，将各模块最小实现补齐为完整项目并完成全链路验收。

原表中的源码阅读、调试与追踪是备课和理解任务，每个业务模块还必须在自己的工程里产出对应最小实现。没有前置代码时先补前置课，不允许在空工程上假设已有登录、列表或数据库。验收自己的实现与验收参考工程须分别记录。

| 第一阶段单元 | 自己项目的最低实现交付 |
|---|---|
| 01–07 | 可独立编写并运行的 Spring Boot 笔记 API，含数据库、校验、事务与异常 |
| 08–14 | 工程骨架、学习数据库初始化、网关路由及自己的登录请求链 |
| 15–21 | 公共响应和异常、基础权限、文档创建/详情/列表、分类与标签 |
| 22–28 | 文档协作、版本和草稿、审核与访问控制、最小文件上传解析链；可拆课实现 |
| 29–35 | 基础配置、跨服务调用、消息通知、最小搜索索引同步和统计链 |
| 36–42 | 对话和会话、写作入口、切块/向量化/检索/回答的最小 RAG 闭环 |
| 43–49 | 图谱抽取与查询、混合检索、更新同步实验，以及阶段性独立实现检查 |

这些交付不是要求在固定日数内仓促全部完成。每次进入单元，按真实代码拆成可理解、可运行、可验收的增量；未完成项写回进度台账，不以看过参考代码替代实现。

正式教学文档必须遵循根目录 `AGENTS.md` 的七段结构。本文是课纲，备课提纲不能替代经过代码核验的完整课程。每日开始先阅读本计划和 `每日进度.md`，再检查当天实际源码。

## 源码定位约定

- 后端根目录：`knowledge-base-backend/`。表中模块均在这里；类名可在 IDEA 中搜索定位。
- 前端根目录：`knowledge-base-frontend/`。前端接口集中在 `src/services/`。
- 现成教程：后端 `docs/`，包含骨架、公共服务、网关封装、文档、分类、标签、评论、版本、审核。
- RAG 入口：`kb-ai/src/main/java/com/knowledge/base/ai/rag/`。
- KAG 入口：上述目录中的 `kag/`；图谱展示与管理还涉及 `kb-graph`。
