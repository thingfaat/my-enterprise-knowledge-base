# My Enterprise Knowledge Base

从真实源码出发，逐步亲手实现企业智能知识库的学习项目。

目标是理解整体架构、数据流与设计取舍，并独立写出、运行和维护完整项目。源码阅读、教学文档和小实验服务于这个目标；最终需要交付自己的前后端实现及可复现的验收结果。

## 当前状态

项目处于学习准备阶段：已建立课程计划、教学规范、进度台账及模板，尚未开始 Day 01，暂无业务代码和可运行应用。后续功能均为学习与实现目标，不表示已经完成。

## 开始学习

1. 阅读 [每日课程计划](learning/每日课程计划.md)，确认当前阶段与目标。
2. 阅读 [每日进度](learning/每日进度.md)，从上次未完成项继续。
3. 按 [AGENTS.md](AGENTS.md) 核对真实源码，编写当日教案。
4. 在本项目中亲手实现、运行并验收，记录问题与理解，更新进度。

每天投入约 4 小时：回顾 15 分钟、原理讲解 45 分钟、源码追踪 60 分钟、独立练习 90 分钟、验收记录 30 分钟。可根据当天实现难度调整，未通过的内容继续学习。

## 学习与实现路线

| 阶段 | 内容 | 交付与完成条件 |
|---|---|---|
| 第一阶段 | 49 个基础与模块学习单元：Spring Boot、登录权限、文档、服务协作、搜索、AI、RAG、知识图谱 | 建立整体理解，并在自己的工程中完成每个模块的最小实现；复杂单元可拆成多个学习日 |
| 第二阶段 | 按 [完整项目实现里程碑](learning/完整项目实现里程碑.md) 补齐各模块及前端页面 | 建立功能与源码对照清单，逐项实现并提供验收证据 |
| 第三阶段 | 全链路联调、异常排查、部署与独立复现 | 从干净环境启动自己的项目，完成端到端演示，解释设计并独立完成变化需求 |

49 天是初始学习安排，不是完整项目的交付期限。看完教程、跑通参考项目或完成一个小需求，都不能替代完整实现验收。

## 目标能力范围

- 工程与公共能力：配置、异常、日志、服务注册、网关和服务间调用。
- 用户与权限：认证、角色权限、用户与团队管理。
- 文档管理：编辑、分类、标签、评论、收藏、版本、自动保存、审核、分享及访问控制。
- 文件管理：上传、管理、解析及与文档的关联。
- 基础服务：配置、字典、通知、消息和实时推送。
- 搜索与统计：索引同步、查询、搜索历史、指标聚合及缓存。
- AI：对话、会话、写作、反馈、文档切块、向量索引、RAG、知识图谱与混合检索。
- 前端与交付：对应业务页面、接口联调、权限交互、异常状态、初始化与启动文档。

以上是待源码核对的范围初稿。每个模块开始前，以参考源码建立功能清单，标明已实现、待实现、疑似缺陷与差异；不能凭文档宣称功能完整。具体进展以进度台账和验收证据为准。

## 教学约定

每课以真实代码为依据，严格按以下顺序组织：

**原理 → 现有数据流 → 本次需要改动的数据流 → 文件位置（复用/新增/修改）→ 基于现有代码的完整增量代码 → 测试验收 → 面试追问。**

- 区分参考实现、自己的当前实现与本课拟实现内容。
- 新增文件提供完整代码，修改文件提供完整可应用增量，并添加解释职责、原理和关键取舍的注释。
- 先尝试自己设计和实现，再对照教学代码检查；逐步减少提示，最终能独立实现变化需求。
- 文档和参考教程可能过时：代码确认实现，实验确认行为，未验证内容明确标注。
- 教案完成、代码完成、测试通过与用户掌握分别记录。
